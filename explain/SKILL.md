# 白话讲解

## 讲解层次（按用户需要切换，默认第一层）

1. **外行层**：这个东西是干嘛的？用生活比喻（比如"垃圾回收就像保洁阿姨"）
2. **入门层**：数据怎么流动？主要函数怎么协作？画 ASCII 图
3. **细节层**：逐段走读关键代码，讲清每个非显然的写法为什么这么写

## 流程

1. 读用户指定的文件/模块（没指定就问）
2. 先给一句话总结：**这段代码的存在理由**
3. 分层展开，每层末尾自查："一个没看过这项目的人读到这里会卡住吗？"
4. 主动指出：这里最容易踩的坑 / 最精巧的写法 / 历史包袱

## 规则

- 比喻要贴切，不为俏皮而俏皮
- 术语第一次出现必须解释（"幂等——做一次和做一百次结果一样"）
- 讲解完留一个检验问题让用户自测（可选，用户嫌烦就跳过）
- 代码引用带 path:line
