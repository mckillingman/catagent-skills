# 日报生成器

## 流程

1. 确定统计范围：默认今天（`git log --since="today 00:00"`），用户可指定日期/分支/路径
2. 收集数据：
   - `git log --pretty=format:"%h %ad %s" --date=format:"%H:%M"` 当日提交
   - `git diff --stat <first>..<last>` 当日累计改动量
   - 多项目时逐个目录跑（用户让查哪些就查哪些）
3. 组织日报：

```
# 工作日报 YYYY-MM-DD

## 项目A
- 完成事项（按提交归类合并，同类合并成一条；写"做了什么"不罗列 hash）
- 改动规模：+XXX / -XXX 行，N 个文件

## 项目B（同上）

## 遗留 & 明日计划
- （从 WIP 提交/未合并分支/未完成的 TODO 推断，标注"推测"）
```

## 规则

- 3 个同类小提交合并成一条（"修复登录页样式问题"而非三条 fix）
- 量化但不堆数字：改动规模一行带过
- 推断的内容必须标注是推断，不编造
- 用户要发钉钉/飞书格式就输出对应 markdown 变体
